Phones
Every phone that has ever signed in or scanned. Give each one a name you recognise, and block one the moment it should no longer be used.
What blocking a phone does, and what it does not.
A blocked phone cannot sign in, cannot start a scanning batch, and — if it is already signed in — is signed out automatically the next time the app checks, which is within about a minute while it is in use, or the moment it is picked up again. Use it when a phone is lost, handed back, or should simply not be used any more. Anything it already scanned stays exactly as it is; blocking stops further work, it never undoes any.
It is not the main control for someone leaving. Each phone makes its own code the first time the app runs. If you clear the app's data on that phone, it gets a new code and a fresh start. When a person leaves, switch their staff account off under Team > People — this stops them signing in on any phone. Blocking the phone is a good extra step, not a replacement.
Why you may see more phones than people: each browser makes a new random code for its phone the first time it runs. If a browser is cleared, or the app is opened in a new browser, the same phone shows up again as a new row marked "Not named yet". Older rows that nobody uses are usually these copies. This list only shows them; it never changes anything.

Edit Access

Employee: —
What a Supervisor can do (signs in with their own code and PIN, then the Supervisor Password):
  • Reset the PIN of a staff member.
  • Unlock a staff member who typed a wrong PIN too many times.
  • Rename a staff member.
  • Turn the phone code on for a staff member, or reset it when they lose their phone.
  • Sign a staff member's phone out (after the next update).
  • Block a lost phone with their own PIN.
  • Do any of the above on their own account.
What a Supervisor cannot do (for these account actions the database itself refuses it, whatever this page shows):
  • Change anything on an Admin or on another Supervisor.
  • Add a person, or switch an account off or on.
  • Change anyone's access or role (this Edit Access box).
  • Archive an account.
  • Change the Admin Password or the Supervisor Password.
  • Use the Supervisor Password with an account that is not a Supervisor for the account actions in the first list (reset PIN, unlock, rename, phone code, phone sign-out). Some other screens, such as the phone list and stock, accept the Supervisor Password on its own.

Settings
Your Admin Password and company details. For people, go to Team > People.

🔑 Change Admin Password

Changing the Admin Password takes effect straight away for everyone using this panel: anyone still using the old password is signed out the next time they open a page. Keep the new password somewhere safe (for example a password manager). It cannot be looked up if lost; it can only be changed again using the current one.

🛡 Supervisor Password

Needed only if someone is a Supervisor (set in Team > People: Add person, or Edit on their row). They sign in with their own employee code and PIN, then unlock this panel with this password — never yours. That is what stops them reaching accounts, access levels and the Admin Password: they do not hold the password those need, so the refusal does not depend on this website behaving itself.

Leave both boxes empty and press Remove it to remove Supervisor access for everyone at once. No account or history is changed.

Recovery email for a forgotten Admin Password

If the Admin Password is ever forgotten, a code is sent to this address. Use an address only the owner can open, and turn on 2-step sign-in for that mailbox.

Rare tools

Bulk update existing products from a spreadsheet (CSV)

Changes the reorder level, cost price, MRP or on/off of many products at once. It never adds products. You see a preview before anything is saved.

⬆ Bulk CSV Import — Update Existing SKUs

Upload a CSV with a sku_code column plus any of reorder_threshold, cost_price, mrp, active (true/false). Only these four fields can be changed here — new SKUs are not created, and product name / ASIN / bin / set size are not touched, even if they are in your file. Extra columns are ignored.

Undo a raw-material import

Puts every row of a recent import back as it was. It works for 24 hours after the import. It opens in Buying, where you type your PIN.

Import templates

Bulk upload template (Excel): ⬇ Download (.xlsx)

Production: open Production in the phone app and use its Import button. It downloads a ready-to-fill sheet with instructions.

Raw materials (items, vendors, opening stock, purchase bills, barcodes): open the phone app, go to Raw materials, then Import / Export. Customers and Production: open that section in the phone app and use its Import button. Each one downloads a ready-to-fill sheet with instructions.

Taken out of this panel

Reset all stock to zero, and Delete all test accounts, are no longer here. They were one-time tools. If one is ever needed, your developer runs it once, with a backup first.

Shopify

Shopify orders come into the app as orders to pick, the same way as the upload sheet. Every switch starts OFF; switching one on is the founder's decision. Your PIN is asked for each step and is not kept.

Couriers (Shiprocket)

A courier can be booked only for an order whose every line is scanned. Every switch starts OFF; switching one on is the founder's decision. Your PIN is asked for each step and is not kept.

CEO Brief

Approve = the Builder Bot on the office laptop builds it tonight on a copy and a separate checker reviews it. It never puts anything live by itself: when it is ready, this page shows the exact file the lead or you run to put it live. Anything that deletes data, spends money or turns on something customers see asks you once more. Your PIN is asked for each step and is not kept.

Raw materials

Where raw materials are kept

In the phone app, on the Raw materials screen. There you record stock in (item, quantity, unit, supplier, price, GST and transport), stock out with a reason, and fix a count. Each item shows stock now, the average and last price, the price by supplier and its reorder level.

Who can use it

A person needs the Raw materials switch. Change it under Team > People: Add person, or Edit on their row.

Price warning

The app warns when a price is more than 10% above the last price for that item. The percentage is changed on the Raw materials screen in the phone app; it asks for your PIN.

Taken out of the app

Purchase orders, goods received, bills and payments, GST register, HSN summary, recipes (BOM), lots, vendor scores and purchase requests are no longer part of the app. Customers, warranty and chats are gone too.

Modules

A person gets a module when it is switched on in their access (Team > People > Edit). A switch that turns a module on or off for the whole company needs a database change and is not in this version.
